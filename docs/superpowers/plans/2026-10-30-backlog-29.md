# Template-Attribute und Creator-Bearbeitung Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Implementer-Modell vom Nutzer festgelegt: Muse Spark 1.3.

**Goal:** Creator markieren Frame-Elemente mit stabilen `data-od-*`-Template-Feldern, bearbeiten sie im ElementPanel, und der reguläre Frame-Write schützt diese Metadaten serverseitig.

**Architecture:** Ein shared Attributvertrag (`shared/prowin/templateAttributes.ts`) wird von Client (DOM in `layers.ts`) und Server (String-Scan über `collectFrameTags`) benutzt. Der Client schreibt Felder über `layerEdits` mit Rollback und Live-Mirror; der Server prüft in `actions.updateFrame` nur Metadaten-Änderungen, keine Inhalte.

**Tech Stack:** TypeScript, React 18, Vitest/happy-dom, bestehende `BRAND_TOKENS`, keine neue Abhängigkeit (kein `linkedom`).

**Spec:** [2026-10-30-template-attributes-design.md](../specs/2026-10-30-template-attributes-design.md), `docs/prowin/doop-fork-umsetzung.md` §9.1/§9.3, `docs/prowin/bezugsdokumente-referenz.md` R1.3–R1.4, Backlog TASK-29.

## Global Constraints

- Attribute exakt: `data-od-id`, `data-od-role`, `data-od-label`, `data-od-locked`, `data-od-max-length`, `data-od-allowed-colors`. Kein `data-od-lock="font,size"` (offen laut R1.4).
- Rollen exakt: `headline | body | image | cta | logo | contact | date | decor`. Keine Kopplung ans HTML-Tag.
- Tokenformat exakt: Token-Namen ohne `--`, komma-getrennt (z. B. `prowin-ci-blau,prowin-ci-orange`); einzige Quelle `BRAND_TOKENS`; Hex ist ungültig.
- ID-Format exakt: `^[A-Za-z][A-Za-z0-9_-]{0,63}$`. ID ändert sich nur per explizitem, validiertem Rename — nie implizit.
- `max-length`: Ganzzahl ≥ 1; leer = ungesetzt. `label`: getrimmt, max. 120 Zeichen. `locked`: Präsenz zählt.
- Minting nur beim Markieren. Frame-/Page-/Canvas-Kopien behalten IDs. Element-Duplikat remintet den Teilbaum.
- Serverprüfung nur in `actions.updateFrame`, semantisch auf Attributen, nie Rohtext-Vergleich. Voller Guard = TASK-30, Beraterinnen-UI = TASK-31 — nicht bauen.
- UI-Texte auf Deutsch. Keine neue Abhängigkeit. Tests mit `TMPDIR=/tmp/opencode bun run test <dateien> --maxWorkers=1` ausführen.

```ts
import { describe, expect, it } from 'vitest'
import {
  extractTemplateFields,
  validateTemplateField,
  diffTemplateMeta,
  mintTemplateId,
  type TemplateField,
} from '../shared/prowin/templateAttributes'

const field = (patch: Partial<TemplateField> = {}): TemplateField => ({
  id: 'titel',
  role: 'headline',
  label: 'Titel',
  locked: false,
  maxLength: null,
  allowedColors: [],
  ...patch,
})

describe('templateAttributes', () => {
  it('extracts fields from real tags only', () => {
    const html = `<html><head><style data-od-brand>:root{}</style></head><body>
      <!-- <h1 data-od-id="fake">x</h1> -->
      <script>var s = '<p data-od-id="fake2">'</script>
      <h1 data-od-id="titel" data-od-role="headline" data-od-label="Titel" data-od-locked data-od-max-length="80" data-od-allowed-colors="prowin-ci-blau, prowin-ci-orange">Hallo</h1>
    </body></html>`
    expect(extractTemplateFields(html)).toEqual([
      { id: 'titel', role: 'headline', label: 'Titel', locked: true, maxLength: 80, allowedColors: ['prowin-ci-blau', 'prowin-ci-orange'] },
    ])
  })

  it('validates id, role, maxLength and color tokens strictly', () => {
    expect(validateTemplateField(field())).toEqual([])
    expect(validateTemplateField(field({ id: '1x' })).length).toBeGreaterThan(0)
    expect(validateTemplateField(field({ role: 'admin' as TemplateField['role'] })).length).toBeGreaterThan(0)
    expect(validateTemplateField(field({ maxLength: 0 })).length).toBeGreaterThan(0)
    expect(validateTemplateField(field({ maxLength: 2.5 })).length).toBeGreaterThan(0)
    expect(validateTemplateField(field({ allowedColors: ['#fff'] })).length).toBeGreaterThan(0)
    expect(validateTemplateField(field({ allowedColors: ['primary'] })).length).toBeGreaterThan(0)
  })

  it('diffs semantically: locked="" equals locked="true", content edits do not count', () => {
    const prev = `<h1 data-od-id="titel" data-od-locked>Alt</h1>`
    const next = `<h1 data-od-locked="true" data-od-id="titel">Neu</h1>`
    expect(diffTemplateMeta(prev, next)).toEqual({ changed: false, duplicates: [], invalid: [] })
    expect(diffTemplateMeta(prev, `<h1 data-od-id="titel">Neu</h1>`).changed).toBe(true)
    expect(diffTemplateMeta(prev, `<h1 data-od-id="titel" data-od-locked>Neu</h1><p data-od-id="titel">x</p>`).duplicates).toEqual(['titel'])
  })

  it('mints unique valid ids', () => {
    const taken = new Set(['feld-aaaaaaaa'])
    const ids = ['aaaaaaaa', 'bbbbbbbb']
    expect(mintTemplateId(taken, () => ids.shift()!)).toBe('feld-bbbbbbbb')
  })
})
```
