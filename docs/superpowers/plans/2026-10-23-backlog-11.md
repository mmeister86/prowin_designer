# TASK-11 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove SSO/OIDC and Microsoft login across server, web, desktop and iOS.

**Architecture:** Keep the existing Better Auth email/password, Google and Apple flows. Replace the public provider-discovery URL with `/api/login-providers`, returning only `google`, `apple` and `appleNative` booleans. Remove the generic OAuth login plugin while retaining MCP's independent OAuth provider.

**Tech Stack:** TypeScript, React, Better Auth, Swift, Vitest.

**Spec:** `backlog/tasks/task-11 - SSO-OIDC-und-Microsoft-Login-aus-allen-Clients-entfernen.md`

- No new dependencies or database deletion; preserve account linking, email verification, signup-domain restrictions and native handoff validation.
- One feature-removal commit: `chore(prowin): remove sso and microsoft login`.
