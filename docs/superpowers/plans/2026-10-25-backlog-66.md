**Architecture:** Eine Zeile in `.prettierignore` nimmt die CLI-eigene `backlog/config.yml` aus Prettiers Prüfung — gleiches Muster wie die bestehenden Einträge für Tool-/Generierungsdateien (`bun.lock`, `desktop/src-tauri/tauri.conf.json`). Die Backlog-Task-`.md`-Dateien bleiben Prettier-geprüft (Husky/lint-staged formatiert sie bereits).

**Tech Stack:** Prettier 3 (`bun run format:check`), Backlog.md CLI.

**Spec:** Backlog TASK-66; CI-Log PR #7 (Job `lint`: `bun run lint` grün, `bun run format:check` warnt nur `backlog/config.yml`).
